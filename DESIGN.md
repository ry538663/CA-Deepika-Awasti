# DESIGN SYSTEM - Income Gain Solutions

## Visual Theme
Minimal, modern, high-contrast. Clean lines, generous whitespace. Professional services feel — like Vercel or Linear but with a warm, trustworthy financial services character. No flat designs.

## Color Palette
- **Primary (Deep Navy)**: #0A1628 — Use for headers, primary buttons, footers
- **Accent (Warm Gold)**: #D4A853 — Use for CTAs, hover states, accent borders, key highlights
- **Secondary Navy**: #1B365D — Use for secondary elements, cards
- **Background**: #F8F6F1 (Warm White) — Use for page backgrounds
- **Surface**: #FFFFFF — Use for cards, modals, sections
- **Text Primary**: #1A1A2E (Charcoal)
- **Text Muted**: #6B7280 (Gray)
- **Border**: #E5E7EB (Light Gray)
- **Success/Trust**: #2D6A4F (Forest Green) — Use subtly for trust badges

## Typography
- **Headings**: Inter or DM Sans (bold, clean)
- **Body**: Inter or DM Sans (regular, highly readable)
- **Font Scale**: Tailwind default scale (text-sm to text-4xl)

## Spacing
- Tailwind default spacing scale
- Generous whitespace — especially around sections and between elements
- Section padding: py-16 to py-24 on desktop

## Component Patterns
- **Cards**: rounded-lg with subtle shadows
- **Buttons**:
  - Primary: Navy with Gold hover
  - Secondary: Gold with Navy hover
- **Navigation**: Sticky header with transparent-to-solid scroll effect
